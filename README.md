# 🌿 منصة عُمْرَان الذكية لإدارة حلقات تحفيظ القرآن الكريم
### *Omran Smart Quran Halaqah Platform*

منصة تعليمية وتربوية متكاملة مصممة خصيصاً لمشرفي ومعلمي حلقات تحفيظ القرآن الكريم، والطلاب وأولياء الأمور. تجمع المنصة بين سهولة الإدارة الميدانية وقوة الذكاء الاصطناعي (Google Gemini 3.7 Flash) كشيخ ومربٍ خبير، لمتابعة الحضور، تقييم التسميع بدقة متناهية وفق الضوابط القرآنية، توليد خطط الحفظ اليومية، إرسال تقارير الواتساب الفورية مع روابط البوابة المباشرة، وطباعة الشهادات والتقارير الدورية.

---

## ✨ المميزات الرئيسية

### 1. 📿 التخطيط القرآني والتقييم بالذكاء الاصطناعي (Gemini 3.7 Flash)
- **شيخ ومربٍ واقعي ومثقف:** يعتمد على نموذج ذكاء اصطناعي منضبط ومزود بقاعدة بيانات كاملة لـ 114 سورة وعدد آياتها بدقة مطلقة (لا أخطاء ولا أرقام آيات وهمية مثل الناس 1-8).
- **تخطيط يومي متكيف:** يحدد ورد الحفظ الجديد وورد المراجعة، ويقترح القارئ المتقن المناسب لعمر ومستوى الطالب (الحصري، المنشاوي، العفاسي، أيمن سويد...).
- **تقييم تفاعلي:** يحلل ما أنجزه الطالب من جديد ومراجعة، ويضبط خطة الغد تلقائياً مراعياً التيسير عند التعثر أو التوسع عند الإتقان.

### 2. 📱 رسائل الواتساب الفورية وروابط البوابة الحية
- **رسائل يومية تفصيلية:** تشمل حالة الحضور، تفاصيل ما تم تسميعه اليوم، مقرر الغد، والقارئ المقترح بنقرة زر واحدة.
- **رابط البوابة المباشر:** كل رسالة تحتوي على رابط مباشر يفتح صفحة الطالب وبوابته الحية فوراً دون الحاجة لتسجيل الدخول أو إدخال كلمات مرور معقدة (`?portal=STUDENT_ID`).

### 3. 👥 إدارة الطلاب والحضور
- تسجيل وتعديل وحذف الطلاب مع حوارات تأكيد مخصصة ومريحة.
- تسجيل الحضور والغياب والتأخر والأعذار بنقرة واحدة وتصدير الكشوفات.

### 4. 📊 التقارير الدورية ولوحة الشرف
- تقارير أسبوعية وشهرية تفصيلية ونسب الحضور ومعدلات التسميع.
- طباعة التقارير وتصدير الشهادات وبطاقات الشرف للمتفوقين.

### 5. 💾 التخزين والمزامنة السحابية
- دعم التخزين السحابي الآمن عبر **Firebase Firestore** مع التخزين الاحتياطي المحلي الذكي **(Local Storage Cache & Backup)**.
- تصدير واستيراد النسخ الاحتياطية بصيغة JSON بنقرة واحدة.

## 🚀 متطلبات التشغيل والتثبيت السريع

### المتطلبات الأساسية
- **Node.js**: الإصدار 18 أو أحدث (يوصى بـ 20+)
- **NPM** أو **Yarn** أو **PNPM**

### خطوات التشغيل المحلي

1. **استنساخ المستودع (Clone repository):**
   ```bash
   git clone https://github.com/YOUR_USERNAME/omran-quran-platform.git
   cd omran-quran-platform
   ```

2. **تثبيت الحزم (Install dependencies):**
   ```bash
   npm install
   ```

3. **إعداد المتغيرات البيئية (Environment Variables):**
   قم بإنشاء ملف `.env` في المجلد الرئيسي بناءً على `.env.example`:
   ```env
   GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
   APP_URL="http://localhost:3000"
   ```

4. **تشغيل الخادم في وضع التطوير (Run Development Server):**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

5. **بناء المشروع للإنتاج (Build for Production):**
   ```bash
   npm run build
   npm start
   ```

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, Canvas-Confetti.
- **Backend:** Node.js, Express, ESBuild.
- **AI Engine:** Google GenAI SDK (`@google/genai`) مع نموذج `gemini-3.7-flash`.
- **Database:** Firebase Firestore & Local Storage Synchronization.
