# 🌿 منصة عُمْرَان لإدارة حلقات ومجمعات تحفيظ القرآن الكريم
### *Omran Quran Halaqah & Academy Management Platform*

منصة تعليمية وتربوية متكاملة مصممة خصيصاً لمشرفي ومعلمي حلقات تحفيظ القرآن الكريم، والطلاب وأولياء الأمور. تجمع المنصة بين سهولة الإدارة الميدانية، الدقة القرآنية في تسجيل التسميع الفردي والمتعدد للسور، تخصيص معايير التقييم، إرسال تقارير الواتساب التلقائية مع روابط البوابة المباشرة لأولياء الأمور، وإدارة الحضور والنسخ الاحتياطي الكامل.

---

## ✨ المميزات الرئيسية للمنصة

### 1. 📖 تسجيل التسميع والتقييم المتعدد للسور (Multi-Surah Evaluation)
- **مرونة كاملة في تحديد النطاق:** إمكانية تسجيل التسميع من سورة وآية إلى سورة وآية أخرى (مثل: من سورة الناس آية 1 إلى سورة العلق آية 4).
- **أقسام متعددة للمراجعة والاختبارات:** إضافة عدد غير محدود من مواضع المراجعة اليومية (مراجعة صغرى، كبرى، تراكمية، اختبار جزء أو ربع يس...).
- **تحديد مقرر الغد يدوياً أو آلياً:** يقوم المعلم بتحديد ورد الحفظ والمراجعة لغد بدقة، مع زر الحساب التلقائي الذكي بناءً على ما أنجزه الطالب اليوم.
- **تخصيص معايير التقييم والدرجات:** إمكانية إضافة وتعديل معايير التقييم (درجات، نجوم، خيارات مخصصة، ملاحظات نصية).

### 2. 📱 رسائل الواتساب الفورية وروابط البوابة الحية
- **رسائل يومية تفصيلية:** تشمل حالة الحضور، تفاصيل ما تم تسميعه اليوم، ومقرر الغد، والقارئ المقترح، وملاحظات الشيخ بنقرة زر واحدة.
- **رابط البوابة المباشر:** يفتح صفحة الطالب الحية فوراً دون الحاجة لتسجيل الدخول أو كلمات مرور معقدة (`?portal=STUDENT_ID` أو البحث برقم الهاتف أو الاسم).

### 3. 👥 إدارة الطلاب والحضور
- تسجيل وتعديل وحذف الطلاب مع مستويات الحفظ والحلقات.
- تسجيل الحضور والغياب والتأخر والأعذار بنقرة واحدة وتصدير الكشوفات.

### 4. 📊 التقارير الدورية ولوحة الشرف
- تقارير إحصائية دورية ونسب الحضور ومعدلات التسميع.
- طباعة التقارير وتصدير كشوفات الإنجاز.

### 5. 💾 النسخ الاحتياطي والأمان التام
- دعم التخزين السحابي الآمن عبر **Firebase Firestore** مع التخزين المحلي التلقائي **(Local Storage Sync & Cache)**.
- تصدير واستيراد النسخ الاحتياطية الكاملة بصيغة JSON بنقرة واحدة لضمان عدم ضياع أي سجل.

## 🚀 التثبيت والتشغيل المحلي (Local Setup)

### المتطلبات الأساسية
- **Node.js**: الإصدار 18 أو أحدث (يوصى بـ 20+)
- **NPM** أو **Yarn** أو **PNPM**

### خطوات التثبيت:

```bash
# 1. استنساخ المستودع
git clone https://github.com/YOUR_USERNAME/omran-quran-platform.git
cd omran-quran-platform

# 2. تثبيت الحزم
npm install

# 3. إنشاء ملف المتغيرات البيئية
cp .env.example .env

# 4. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 🌐 دليل الرفع والاستضافة على GitHub والنشر (GitHub & Deployment Guide)

### 1. إنشاء مستودع جديد على GitHub:
1. اذهب إلى [GitHub](https://github.com/new) وأنشئ مستودعاً جديداً باسم `omran-quran-platform`.
2. قم بربط مشروعك المحلي بالمستودع ورفع الملفات:

```bash
git init
git add .
git commit -m "الإصدار الأول - منصة عمران لإدارة حلقات القرآن الكريم"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/omran-quran-platform.git
git push -u origin main
```

### 2. خيارات الاستضافة والنشر السحابي المجاني:

#### الخيار أ: النشر على **Vercel** (موصى به لسرعته وسهولته):
1. سجل دخولك على [Vercel](https://vercel.com) باستخدام حساب GitHub.
2. اضغط على **"Add New Project"** واختر مستودع `omran-quran-platform`.
3. اضغط **Deploy**. سيعمل المشروع فوراً مع شهادة SSL مجانية ورابط دائم.

#### الخيار ب: النشر على **Render** أو **Railway** أو **Cloud Run**:
- أمر البناء (Build Command): `npm run build`
- أمر البدء (Start Command): `npm start`
- المنفذ الافتراضي (Port): `3000`

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, Canvas-Confetti.
- **Backend:** Node.js, Express, ESBuild.
- **Database & Sync:** Firebase Firestore & Local Storage Synchronization.
